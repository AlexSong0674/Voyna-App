# Step 3: 카카오 디벨로퍼스 + 카카오 로그인 셋업

> 예상 소요 시간: **10분**  
> 비용: **무료** (월 10만 호출까지 무료, MAU 5만 한도 내)

---

## 🎯 이 단계의 목표

사용자가 앱에서 **"카카오로 시작하기"** 버튼을 누르면 자동으로 회원가입·로그인되도록:

```
[앱 카카오 버튼] → 카카오 인증 → Supabase JWT 발급 → 자동 가입 + 홈 화면
```

---

## 1️⃣ 카카오 디벨로퍼스 가입 (1분)

1. **https://developers.kakao.com** 접속
2. 우측 상단 **"로그인"** 클릭 (본인 카카오 계정 사용)
3. 첫 로그인 시 약관 동의 + 이메일 등록 → 완료

---

## 2️⃣ 새 애플리케이션 생성 (2분)

1. 상단 **"내 애플리케이션"** 클릭
2. 노란색 **"애플리케이션 추가하기"** 버튼

3. 입력값:
   ```
   ┌─────────────────────────────────────────┐
   │ 앱 이름:    Voyna                        │
   │ 사업자명:   AlexSong (또는 본인 이름)     │
   │ 카테고리:   (선택사항)                   │
   └─────────────────────────────────────────┘
   ```
   → **저장** 클릭

4. 생성된 앱 카드를 클릭해서 들어가기

---

## 3️⃣ 핵심 키 4개 복사 (1분)

좌측 메뉴 **"앱 설정"** → **"앱 키"**:

다음을 메모장에 복사 (나중에 알려주실 것):

```
✅ 네이티브 앱 키:   (앱에서 카카오 SDK 초기화용)
✅ JavaScript 키:    (웹 미리보기·디버깅용)
✅ REST API 키:      (서버 측 + Supabase OAuth 등록용)  ← 가장 중요
   (Admin 키:        ❌ 절대 공유 X)
```

---

## 4️⃣ 플랫폼 등록 (2분)

좌측 **"앱 설정"** → **"플랫폼"** → **"iOS 플랫폼 등록"** 클릭:

```
번들 ID:        app.voyna
앱스토어 ID:    (출시 후 입력 — 지금은 비워둠)
마켓 URL:       (지금은 비워둠)
```

저장.

같은 방식으로 **"Android 플랫폼 등록"**:
```
패키지명:       app.voyna
마켓 URL:       (비워둠)
키 해시:        (Phase 3 — 앱 빌드 후 추가)
```

---

## 5️⃣ 카카오 로그인 활성화 (3분) — 가장 중요한 단계

좌측 **"제품 설정"** → **"카카오 로그인"** → 상단 **"활성화 설정"** 토글을 **ON**

### 5-1. Redirect URI 등록

같은 페이지의 **"Redirect URI"** 섹션에서 **"Redirect URI 등록"** 클릭:

```
https://wucbvyxneegbpjvamhfo.supabase.co/auth/v1/callback
```

(이 URL은 Supabase가 카카오 OAuth 콜백을 받는 자동 생성 URL입니다.)

→ **저장**

### 5-2. 동의항목 설정

좌측 **"제품 설정"** → **"카카오 로그인"** → **"동의항목"**:

| 항목 | 동의 단계 | 필수 여부 |
|------|----------|----------|
| 닉네임 | 필수 동의 | ✅ |
| 프로필 사진 | 선택 동의 | (선택) |
| 카카오계정(이메일) | 선택 동의 | (권장 — 향후 이메일 마케팅용) |

각 항목 우측 **"설정"** 클릭하여 변경.

### 5-3. 보안 — Client Secret 발급

좌측 **"제품 설정"** → **"카카오 로그인"** → **"보안"**:

**Client Secret** 섹션에서 **"코드 생성"** 클릭. 생성된 secret을 메모장에 복사:
```
✅ Client Secret:  (Supabase에 등록할 것)
```

그 다음 같은 페이지에서 **활성화 상태**를 **사용함**으로 설정.

---

## 📥 완료 후 알려주실 정보

다음 2개를 채팅으로 알려주세요 (네이티브 키, JavaScript 키는 나중에 앱 코드에 들어감):

```
✅ 카카오 디벨로퍼스 가입 완료
✅ Voyna 앱 등록 완료
✅ Redirect URI 등록 완료
✅ 동의항목·Client Secret 설정 완료

REST API 키:    abcdef123456...
Client Secret:  xyz789abc...
```

→ 제가 즉시 Supabase Auth에 카카오 provider를 자동 등록합니다 (Management API 사용).

---

## 🚨 문제 해결

| 증상 | 해결 |
|------|------|
| "사업자 등록증이 필요합니다" 안내 | 무시 OK — 개인 개발자도 가능 |
| Redirect URI 저장 시 빨간 메시지 | URL을 정확히 복사했는지 확인 (https://...callback까지) |
| Client Secret이 안 보임 | 카카오 로그인이 활성화 OFF면 안 보임 — 5단계 먼저 |
| 동의항목 "선택 동의 사용 불가" | 카카오 정책상 일부 항목은 비즈 채널 인증 필요 — 닉네임만 있어도 충분 |
