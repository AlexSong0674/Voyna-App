# Step 4: Google Cloud Console + Google OAuth 셋업

> 예상 소요 시간: **10분**  
> 비용: **무료** (OAuth는 무제한 무료, 다른 API는 사용량 한도 내 무료)

---

## 🎯 이 단계의 목표

사용자가 앱에서 **"Google로 시작하기"** 버튼을 누르면 자동 회원가입·로그인되도록.

---

## 1️⃣ Google Cloud Console 가입 (1분)

1. **https://console.cloud.google.com** 접속
2. 본인 Google 계정으로 로그인
3. 첫 접속 시 약관 동의 → 국가 한국 선택 → 완료

---

## 2️⃣ 새 프로젝트 생성 (2분)

1. 상단 메뉴 좌측의 프로젝트 선택기 (현재는 보통 "프로젝트 선택" 표시) 클릭
2. 우측 상단 **"새 프로젝트"** 클릭
3. 입력값:
   ```
   프로젝트 이름:  Voyna
   조직:           (개인이면 공란)
   ```
   → **만들기** 클릭

4. 약 30초 대기 → 알림창에서 **프로젝트 선택** 클릭 (또는 상단 선택기에서 Voyna 선택)

---

## 3️⃣ OAuth 동의 화면 구성 (3분)

좌측 햄버거 메뉴 (☰) → **"API 및 서비스"** → **"OAuth 동의 화면"** 클릭

### 첫 화면: User Type 선택
```
○ 내부 (Google Workspace 조직만)
● 외부 ← 선택  (일반 사용자 누구나)
```
→ **만들기** 클릭

### OAuth 동의 화면 정보 입력
```
앱 이름:         Voyna
사용자 지원 이메일:  본인 Gmail
앱 로고:         (선택 — 나중에 업로드)

앱 도메인 (모두 선택사항 — 출시 후 등록):
- 앱 홈페이지:    (비워둠)
- 개인정보처리방침: (비워둠)
- 서비스 약관:    (비워둠)

승인된 도메인:
+ 추가 클릭 → "supabase.co" 입력

개발자 연락처 정보:
이메일:  본인 Gmail
```
→ **저장 후 계속** 클릭

### 범위 (Scopes) — 그대로 진행
- 별도 추가 없이 그냥 **저장 후 계속** 클릭

### 테스트 사용자 — 본인 이메일 추가
```
+ ADD USERS 클릭 → 본인 Gmail 입력 → 추가
```
→ **저장 후 계속** 클릭

### 요약 → **대시보드로 돌아가기**

### 게시 상태 변경 (중요!)
화면에서 현재 게시 상태가 **"테스트"** 일 텐데, 그대로 두면 본인 + 테스트 사용자만 로그인 가능합니다.

**임시 권장**: MVP 베타 단계에서는 "테스트" 유지 → TestFlight 베타 시 100명을 테스트 사용자로 등록  
**정식 출시 시**: "프로덕션으로 푸시" 버튼 → 구글 심사 (보통 자동 통과, 1~2일)

→ 지금은 **테스트 상태 유지**.

---

## 4️⃣ OAuth 클라이언트 ID 생성 (3분)

좌측 메뉴 **"사용자 인증 정보"** 클릭 → 상단 **"+ 사용자 인증 정보 만들기"** → **"OAuth 클라이언트 ID"**

### 애플리케이션 유형
```
● 웹 애플리케이션  ← 선택 ⭐
```

> **왜 "iOS"가 아닌가?** Supabase Auth는 백엔드(웹)에서 OAuth 콜백을 받는 구조이기 때문에, iOS 네이티브 SDK가 아닌 **"웹 애플리케이션"** 유형을 선택해야 합니다.

### 입력
```
이름:  Voyna Supabase Auth

승인된 자바스크립트 원본:
(비워둠)

승인된 리디렉션 URI:
+ URI 추가 클릭
입력:  https://wucbvyxneegbpjvamhfo.supabase.co/auth/v1/callback
```

→ **만들기** 클릭

### 생성된 키 2종 즉시 복사

팝업에 두 값이 표시됩니다:

```
✅ 클라이언트 ID:  xxxxxxxxxxxx-yyyyyyyy.apps.googleusercontent.com
✅ 클라이언트 보안 비밀번호 (Secret):  GOCSPX-xxxxxxxxxxxxxxxxxxxx
```

⚠️ Secret은 한 번 닫으면 다시 보기 어려우니 **즉시 메모장에 복사**.

---

## 📥 완료 후 알려주실 정보

```
✅ Google Cloud 프로젝트 Voyna 생성 완료
✅ OAuth 동의 화면 구성 완료 (외부, 테스트 상태)
✅ OAuth 클라이언트 ID 생성 완료

클라이언트 ID:      xxxx-xxxx.apps.googleusercontent.com
클라이언트 Secret:  GOCSPX-xxxx
```

→ 제가 즉시 Supabase에 Google OAuth provider 등록 + PAT 폐기 안내까지 마무리하겠습니다.

---

## 🚨 문제 해결

| 증상 | 해결 |
|------|------|
| OAuth 동의 화면 "범위 추가" 강제 요구 | 그냥 저장 후 계속 (기본 범위로 충분) |
| 리디렉션 URI 저장 시 빨간 메시지 | URL 정확히 복사 확인 (https://...callback까지) |
| "이 앱은 확인되지 않았습니다" 경고 | 테스트 상태라 정상 — 출시 시 프로덕션 전환 |
| 프로젝트가 없다고 표시 | 상단 선택기에서 Voyna 프로젝트 다시 선택 |

## 다음 단계 (자동)

Google 클라이언트 ID + Secret 알려주시면:
1. Supabase에 Google provider 자동 등록
2. PAT 폐기 안내
3. (선택) **임시 테스트 사용자 생성** — 카카오·구글 둘 다 가짜 사용자로 시뮬레이션 테스트
4. → **Phase 3: Flutter 앱 코드 작성 시작** 🚀
